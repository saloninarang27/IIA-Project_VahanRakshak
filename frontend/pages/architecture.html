Tier 1 • Local Schemas

5 Independent Agency APIs

Operates on distinct SQLite databases with zero shared foreign keys and deliberate column name heterogeneity for vehicle identifiers:

  • IIB (Port 5002): registration_no
  • MoRTH VAHAN (Port 5003): vehicle_registration_id
  • Police CCTNS (Port 5004): vehicle_no
  • Highway ANPR (Port 5005): plate_number
  • e-Challan (Port 5006): vehicle_identifier
Tier 2 • Global Coordinator

Central Mediator (Port 5001)

The core brain of the system. Implements query decomposition, canonical key translation, and the Cache-Aside engine:

  • Query Decomposer: Splits 1 inquiry into 5 parallel API calls
  • Cache-Aside Engine: Serves hits in <2ms from DWH
  • Stale Reconciliation: TTL expiry, If-Modified-Since validation, and webhook invalidation
  • Pure Rule Engine: Evaluates Section 196 compliance & risk level
Tier 3 • Global Warehouse

Kimball Star Schema DWH

Denormalized analytical warehouse optimized for high-speed reporting and fleet intelligence:

  • FACT_VEHICLE_EVENT: 10,000+ lifecycle events
  • Conformed Dimensions: DIM_VEHICLE, DIM_LOCATION, DIM_DATE, DIM_STATUS
  • Materialized Views: mv_vehicle_complete_history
  • SQL Pagination: Sub-5ms page slicing (LIMIT/OFFSET)

🔄 Cache-Aside & Stale Data Reconciliation Architecture

To eliminate redundant network roundtrips while ensuring real-time freshness when an agency updates records:

1. Cache-Aside Lookup
Incoming request checks DWH cache first. If present and fresh, served in <2ms.
2. TTL Expiry Check
Cached records expire after 300s. Stale queries trigger an automated background re-sync.
3. Webhook Invalidation
When an e-Challan is issued or policy modified, agency API immediately purges the cached record.
4. Force Live Sync
Frontend "⚡ Force Live Sync" button explicitly bypasses cache for real-time live demonstrations.
