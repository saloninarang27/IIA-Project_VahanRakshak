🧩 Approximate Vehicle Matching & Data Cleansing

Match scanned or noisy registration numbers against the plates held by all five agency databases (VAHAN, IIB, Police, ANPR, e-Challan) using Jaro–Winkler, Levenshtein and an OCR-aware edit distance, then decide — with make, model, colour and type as evidence — whether to accept, correct, reject or flag each record. Noisy identifiers in the agency databases themselves are corrected in place; every decision is logged with the original value.

Scans the live records of all five agency databases — through each agency's own service — for vehicle identifiers that are not a clean registered plate: OCR misreads, typos, formatting noise, unregistered plates and suspicious registry entries. Each one is decided by the same rules (R1–R9) using the make, model, colour and type found in that row, or in a camera sighting of the same reading. Apply writes the corrections back to the agency database; uncertain rows wait for a reviewer. The original value of every changed row is kept in the change log.
